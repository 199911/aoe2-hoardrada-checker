Hoardrada Checker

Checks your Age of Empires II: DE profile for the "Hoardrada" (Viking Sagas) achievement bug. It never changes your original file. If it finds a problem, it can build a fixed copy.

Drop your Player.nfp here
Optional, for the fix: also nocam1.xsdat and nocam2.xsdat from the local profile folder

Your file is read inside this page, in your browser. Nothing is uploaded. The source is two small files you can read.

Where is Player.nfp?

Mac (Steam cloud copy):
~/Library/Application Support/Steam/userdata/<your id>/813780/remote/Player.nfp

Mac (local copy):
~/Library/Application Support/Feral Interactive/Age Of Empires II/VFS/User/Games/Age of Empires 2 DE/<steam id>/profile/Player.nfp

Windows:
C:\Users\<you>\Games\Age of Empires 2 DE\<steam id>\profile\Player.nfp or the Steam userdata\<your id>\813780\remote folder.

On Mac, in Finder use Go > Go to Folder (Shift+Cmd+G) and paste the path.

#MissionItemCh 1 listCh 2 listCh 3 listStatus

1 and 2 are the two decision choices (which is which depends on the item). -1 means the game has this item recorded as not collected. A dash means that chapter's list has no entry.

Fix the stale items

This makes a fixed copy. Your original file is not changed. Each stale -1 becomes the value already recorded for that item in the chapter where you collected it:

    Before you use the fixed files:

    1. Quit the game and Steam completely.
    2. Back up the original files (copy them somewhere safe).
    3. Replace the original Player.nfp with the fixed copy. Rename it back to Player.nfp. Do this in both the Steam cloud folder and the local profile folder, so Steam Cloud does not restore the old one. Do the same for any .xsdat files.
    4. Start the game and reopen the last campaign you played (Chapter 3, "The Last Viking"). This was enough to unlock the achievement for the person who found this, but there is no guarantee it works for you.
